# Student Record Management System

## Introduction

This project is a console-based Student Record Management System developed in C++. It is being built as a learning project to strengthen my understanding of programming concepts such as arrays, functions, file handling (in later versions), and structured program design.

The project will be developed gradually, with each version introducing new features and improvements. Separate README files are maintained for each version to document the changes, newly implemented features, and future plans.

The primary objective of this project is to practice problem-solving and improve my C++ programming skills by building a practical application from scratch.

## Project Status

🚧 Currently under development.

## Planned Features

- Add student records
- View all records
- Search for a student
- Update student information
- Delete student records
- Sort records
- File storage (future version)
- Improved user interface
